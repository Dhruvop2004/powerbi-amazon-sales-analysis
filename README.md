# 🔍 Project Overview
# ✅ Dashboard Purpose: Visualize and analyze Amazon sales data to uncover key business insights and support decision-making.

# 📊 KPIs Included:

Total Sales

Total Orders

Profit Margins

Return Rates

# 🛒 Category-Level Analysis:

Product Category and Sub-category breakdowns

Brand-wise performance tracking

# 🌍 Geographical Insights:

Region and Country-wise sales distribution

Interactive map visualizations for location-based trends

# 📈 Trend & Time Series Analysis:

Monthly and yearly comparisons

Seasonality and sales performance over time

# 👥 Customer Metrics:

Average Order Value

Return Rate Analysis

Buyer behavior trends

# 🧰 Technologies Used:

Power BI Desktop

DAX (Data Analysis Expressions)

Power Query (M)

Data Modeling & Relationships

# 🎯 Business Value:

Enables better sales and inventory decisions

Identifies revenue drivers and underperforming segments

Supports marketing and strategic planning through real-time insights
